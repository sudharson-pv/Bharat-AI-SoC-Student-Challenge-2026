- Primary benchmark device: Motorola Moto G54 5G, MediaTek Dimensity 7020, `arm64-v8a`.
- Secondary test target: Android Studio emulator, `x86_64`.
- Initial languages: English, Tamil, Hindi, Kannada.
- Candidate runtime: ExecuTorch 1.4.0 + XNNPACK with Llama 3.2 1B Instruct `8da4w`, pending proof-of-concept on the physical Moto G54.
